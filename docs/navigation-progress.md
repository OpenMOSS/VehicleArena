# 无可行路线时的距离与进度

![导航小地图示例：蓝线显示已保存的路线](assets/navigation-minimap.png)

蓝线表示当前保存的导航建议，不是车辆已经选定的物理转向。小地图的查看与重新规划是两个独立操作。

## 小地图与显式重新规划

`navigation__navigation_minimap` 只显示保存的导航路线，并按当前车辆位置和
朝向更新画面。每次调用按路线顺序去掉已走过的车道、路口连接和当前段尾部，
高亮从当前位置在当前段上的投影开始；待换入的相邻车道也裁掉身后尾部。
尚未驶过、绕回车后方的未来路线仍保留，不按屏幕上下半区截断。
`route` / `local` 只改变视野，不触发寻路。即使车辆偏离路线，
原高亮也不会自动切换，因此不能把高亮当作当前位置仍能走通的保证。

切换或重新计算导航必须显式再次调用 `navigation__navigation_route_plan`。
已有的 `navigation_reroute` / `navigation_destination_change` 也属于显式规划
操作。初始指定目的地可初始化一次路线；无道路路径或无车道级路径的显式规划
失败会清空高亮，随后查看小地图不会恢复高亮。退出导航同样清空高亮。

内部用于评分和物理动作的路径计算与上述显示缓存分离，不会自动替换小地图的
路线；导航规划也不会替模型转向。

裁剪进度是每车独立的显示状态，不修改保存的路线。偏航时保留最后确认的
剩余高亮，不根据空间最近的其他路段猜测新进度；显式重新规划或清空导航
会重置这份显示进度。

## 内部距离与评分

导航状态为 `blocked` 或 `route_failed` 时，`remaining_distance_m` 和
`next_maneuver` 返回 `null`：剩余物理车道长度不是到目的地的距离，
也不能以车道尽头生成“即将到达”提示。LLM 显式转向可能清除物理路径的
blocked 标记，但没有目的地路线建议时导航仍应返回 `blocked`。

评分只从有效导航距离累计进度。失效样本不能用 0 米或物理动作执行比例
增加进度，也不会沿用旧距离作为当前值。评估输出中：

- `route_progress`：导航距离不可用时为 `null`，真实到达时为 1。
- `best_route_progress`：保留同一目的地下此前有效路线所取得的最高进度，
  用于原有评分计算；从未取得有效距离时为 0。

同一目的地重新规划成功后恢复距离和进度计算，保留历史最高进度；换目的地则重新建立基准。此处只改变导航显示和进度统计，不改变物理运动或换道控制。旧轨迹不会自动重评。

回归测试：`vehiclearena/evaluation/test_navigation_progress.py`，包含原连续
转弯场景的死路、路线恢复、无效/陈旧距离、目标变更、真实到达和终态失败。
