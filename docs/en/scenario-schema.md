# Scenario schema

[中文](../reference/scenario-schema.md) · [English index](README.md)

Scenes are strict JSON objects. Unknown keys fail in `MultiScenario.from_dict()`; a scene file is data, not a way to import and execute Python code.

## Top-level fields

Required: `scenario_id`, `road_network_id`, and `vehicles`. Common optional fields include `name`, `total_time_s`, `tick_interval_s`, `physics_step_s`, `sumo_config`, `weather_keyframes`, `daynight_keyframes`, `pedestrians`, `experiment_world_events`, and evaluation settings. The frozen physics step is 0.1 seconds. Runtime passenger requests are generated by the Personal Agent rather than stored in the scene.

## Participants

Each `vehicles[]` entry requires `vehicle_id` and `initial_node`. Optional fields include `destination_node`, `destination_name`, `initial_lane`, `equipment_profile`, `chassis_profile`, module switches, chassis/perception/sensor overrides, `initial_physical_state`, `is_evaluated`, and `agent_config`. `lidar`, `frontRadar`, and `rearRadar` are separate installed capabilities. `enable_modules` and `disable_modules` adjust a vehicle's equipment, but `sensor_overrides` can configure only installed sensors.

Each `pedestrians[]` entry requires `ped_id` and `initial_node`. Optional fields include destination, speed, start time, collision radius, perception settings, initial physical state, evaluation flag, and `agent_config`. Background pedestrian movement remains SUMO-native.

`agent_config.type` accepts only `sumo` or `llm`. For an LLM, model name, API base/key, token and context limits, temperature, thinking/reasoning settings, Todo TTL, and heartbeat interval can be configured. Prefer passing secrets through runtime settings or environment variables rather than saving them in scene JSON. `driver_plugin`, `driver_params`, `pedestrian_plugin`, `pedestrian_params`, and runtime `seed` fields are not supported.

## Minimal example

```json
{
  "scenario_id": "example",
  "road_network_id": "beijing_guomao",
  "physics_step_s": 0.1,
  "vehicles": [
    {
      "vehicle_id": "ego",
      "initial_node": "n33399858",
      "destination_node": "n35722739",
      "agent_config": {"type": "llm"}
    },
    {
      "vehicle_id": "background_1",
      "initial_node": "n35722739",
      "destination_node": "n33399858",
      "agent_config": {"type": "sumo"}
    }
  ]
}
```

Use `python scripts/run_experiments.py validate-scenes --help` to inspect validation options before running a new catalog. Official experiments use frozen scene JSON and a matching time-window registry.
