# 无自动避险的路线边界处理

LLM 车辆没有唯一合法直行、也没有已选择的转向时，系统不发送额外决策提醒，
不设置 SUMO stop，也不改变目标速度或制动能力。模型根据正常唤醒时的画面
和自行查询的导航作出决定。
LLM 可以在到达边界前自行刹车或选择合法转向；已经进入的连接段不改方向。

SUMO 原生移除到达路线端点的车辆后：

- 真正到达指定目的地：沿用 `arrived`。
- 未到达目的地且无法继续模拟：记录 `route_failed=true`，原因为
  `unresolved_route_endpoint`，并保存失败时间、最后实测车道/速度及已安装路线。
- 同一物理步发生真实接触：原生碰撞优先，不额外伪造路线失败或撞墙记录。

这里的路线失败可能是未选择转向，也可能是没有出口的车道；不代表一定存在
实体障碍物。系统不修改地图，不给车辆自动选路，不补红灯/跟车/碰撞避险。

失败车辆保持 `arrived=false`、`present_in_physics_world=false`。保留最后实测
运动值作为退出证据，不伪造瞬时停车；退出后不再追加运动轨迹、计驾驶时间或
出现在其他车辆的空间查询/渲染/雷达中。该车不再收到 Driver/PA 常规唤醒，
PA/Judge 通过终态流程收尾，后续驾驶控制被拒绝；其他车辆继续。
所有车辆均到达、碰撞或路线失败时才满足整场提前结束条件。

回归测试 `vehiclearena/evaluation/test_route_boundary_failure.py` 覆盖短车道、单车/多车、完整调度、终态回调和离线指令重放。测试以 SUMO 的实际位移与终态为准，不把控制窗口结束当成已经换道或到达。
